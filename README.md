# Bank Marketing Campaign Analysis

## Project Overview
This project analyzes the Bank Marketing dataset to understand factors that influence whether a client subscribes to a term deposit.

The goal is to identify customer segments with higher subscription probability and generate business insights that can improve marketing strategies.

---

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

---

## Dataset Features
The dataset contains information about:

- Age
- Job
- Marital Status
- Education
- Contact Month
- Call Duration
- Previous Campaign Results
- Target Variable (Subscription)

---

## Key Analysis Performed

### Data Understanding
- Dataset structure
- Missing value analysis
- Data type inspection

### Exploratory Data Analysis
- Subscription rate analysis
- Age group segmentation
- Job-wise subscription trends
- Monthly campaign performance
- Call duration vs subscription probability

---

## Key Insights

- Customers aged **30–50** showed higher subscription probability.
- Certain job categories had significantly higher conversion rates.
- Campaign performance varied by **month**, indicating seasonal effects.
- Longer call duration strongly correlated with successful subscriptions.

---

## Business Recommendations

- Target high-conversion job segments.
- Focus campaigns in high-performing months.
- Train call agents to improve engagement during calls.
